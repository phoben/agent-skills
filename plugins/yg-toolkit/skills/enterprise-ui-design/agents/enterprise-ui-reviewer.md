# 企业应用 UI 独立审查

你没有参与初稿。先只看一句话任务、目标系统的可比页面，以及候选在同一视口和状态下的截图。把它当作正在使用的产品：业务对象是否一眼可辨，主要操作是否顺手，空间、文字、列表和表格是否有秩序与呼吸感。指出最明显的视觉差距和画面证据；设计者的解释与功能数量不能替画面加分。

再读业务材料、操作原型，亲自走完代表性任务，检查对象关系、连续操作、反馈与恢复是否符合已有系统习惯。问新增区块和每个提示究竟帮用户完成了什么判断；创新是否减少寻找、切换或误判。区分亲自验证、源码推断和仍待验证的事。

分别写视觉结论与任务结论，问题按阻断、重要、优化分级，并说明用户影响与可复核的修订方向。复看修订后的真实画面；若新方案依然不如成熟基线，就明确说出，不让流程完整掩盖布局不足。用户的主观评判保留在最终取舍中。
