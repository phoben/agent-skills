# 方法来源与边界

这些来源提供思考线索，不要求目标项目安装其技能、脚本或设计系统。名称辨认、原文证据与取舍详见 [调研记录](../../../../../docs/research/2026-09-24-enterprise-ui-skill-methods.md)。

- [Anthropic frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)：从真实主题与内容形成设计判断；让文字和视觉结构传达信息；用截图反省默认模板。其鲜明品牌风格与动效诉求不作为企业工作台的默认方向。
- [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/main/.claude/skills/ui-ux-pro-max/SKILL.md)：针对具体问题查找合适知识，再判断其与场景是否相符。无需移入它的风格、色板、字体、规则数据库和检索脚本。
- [Frontend Design Pro](https://github.com/PGraeff/frontend-design-pro-agent-skill/blob/main/skills/frontend-design-pro/SKILL.md)：已有产品行为和设计系统先于视觉新意；界面文案要帮助决策、行动与恢复。它是上述设计技能的派生，不作为独立原创来源计算。
- [Product Design and UX](https://github.com/magnus919/agent-skills/blob/main/product-design-and-ux/SKILL.md)、[ui-design](https://github.com/mblode/agent-skills/blob/main/skills/ui-design/SKILL.md)：前者提醒从对象关系与任务连续性组织界面，后者强调截图审查和先删减再修饰；两者的交付模板与技术约束不移入本技能。
- [Ant Design](https://ant.design/docs/spec/introduce)、[SAP Fiori](https://experience.sap.com/fiori-design-web/)、[Carbon](https://carbondesignsystem.com/)：只作为成熟企业系统的信息组织和一致性参照。实际项目的主题、组件与操作习惯优先。
- [Anshu Chimala 在 Lenny's Newsletter 的文章](https://www.lennysnewsletter.com/p/how-to-turn-your-ai-into-a-world)（公开部分）：借鉴方向发散、独立视觉批评与删减；不把随机风格、图片或动效作为 B 端默认方法。
