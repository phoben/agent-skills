# 技能修订后的视觉布局复测

## 比较对象

保留未使用技能的 A 首稿。C 为独立代理在相同 BOM 业务简报下使用修订技能生成的新原型；C 不读取 A、B 或前轮评价。C 若包含多个结构候选，分别看其默认推荐版与可切换版。首稿截图和原型均保留；审查修订另记。

## 主评价：布局和视觉细节

在 `1440×900` 与 `1280×720` 的初始、编辑、复制后状态分别观察：

1. 导航栏与主工作区的宽度是否与承载的信息量匹配；主表关键列和编辑空间是否被挤压。
2. 成品和版本的定位方式是否清楚，同时避免为了少量信息占用过多横向空间。
3. 卡片或列表项是否用标题、描述、分隔、标签形成易扫读的层级；字号、字重、行高、内边距和间距是否协调。
4. 子件表的来源、用量、单位、规格与约束是否便于横向核对；输入、只读、状态标签是否统一且不抢主数据注意力。
5. 新结构是否让某个真实任务更容易完成，还是仅换了排布。用户对“耳目一新”和美观的主观判断单独记录，代理不得代替。

每项列具体截图和可见位置，允许 A 胜出或无明显差异。流程确认、状态覆盖、键盘能力另写，不给布局加分或抵分。原型只用本地模拟数据；大数据、角色权限和真实服务端不在此测试内。
