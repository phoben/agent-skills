# 截图盲评 V3

任务：维护三行 BOM，修改已有子件用量和临时子件规格并核对。

## 视觉排序

1. **X**
2. **Y**

差异为**中等**：X 的视觉完成度更高，但不足以说明 Y 的业务处理方式没有价值。

## 观察

X 的左侧 SKU 列表有稳定的卡片层级：标题、说明、版本信息和选中态形成了自然的阅读节奏；左侧宽度与表格宽度也较均衡。右侧把编辑直接落在对应表格单元格里，表头、行高、输入框和操作区的密度相互匹配，视线能从“当前 BOM”顺畅落到两个正在修改的字段。唯一显眼的小问题是“必需”被做成了高亮底色，视觉重量略高于其信息价值。

Y 的左栏更收敛，给主表留下更多宽度；“完整 BOM 基线”与“本次变更单”的分区也能被一眼辨认。不过表格的纵向留白偏多，而变更单内两张编辑卡片的文字、标签、箭头和输入框同时争夺注意力，形成两套相近但不完全统一的层级。页面下半部的编辑区因此更像一张说明性面板，少了 X 那种直接、紧凑的操作节奏。字体颜色和细字说明也比 X 多，扫描时需要更多停顿。

## 任务可见性

两张图都能在一屏内看到三条 BOM 与两处修改。Y 可以从画面推断出“基线 + 差异单”的工作方式，X 则把修改动作直接嵌入完整清单；这是流程表达的差异，未计入上面的视觉排名。
