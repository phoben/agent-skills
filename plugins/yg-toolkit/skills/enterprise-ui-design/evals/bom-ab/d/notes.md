# 标准 BOM 维护原型（D）

## 方向与取舍

本稿把任务拆为“定位版本、编辑整树、提交核对”三个连续动作。探索过三种结构：传统列表进入全屏编辑页，主表加右侧详情抽屉，以及版本工作台。最终选择版本工作台：左栏保留成品与版本的上下文，中央以中等密度表格完成行内编辑，右栏始终给出全量子件的提交前核对。它让用户在修改外壳和临时垫片时无需离开版本关系，也能在提交前一眼复核三个子件。

视觉参照采用现有后台事实中提到的浅色背景、中等密度表格、克制状态色和清晰行级信息。删去了与三项任务无关的指标卡、复杂筛选器、发布审批入口与版本差异图，避免把注意力从当前版本和整树保存带走。

## 交互边界

- 可筛选并查看 CP-1008 的 V3、V2，保存后可从 V3 复制出 V4 草稿。
- 可编辑外壳用量和临时垫片规格；已有 SKU 规格展示为只读，临时物料展示为虚拟件。
- 修改后切换版本或返回会提示放弃修改；保存与复制均为内存模拟。
- 未实现真实权限、后端整树写入、并发冲突、发布审批、大数据量加载及真实账号主题验证。
