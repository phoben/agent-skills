# Tokens 用量工作台原型

已选定 C「流量对照板」：项目每日柱、所选范围合计与桑基源节点逐行对应。固定项目→会话两层。

[打开页面](index.html)，或访问本机预览 http://127.0.0.1:48764/ 。本目录包含所有依赖，可直接离线打开，无需安装包或构建。

## 已完成

- 官方账号总量和每日趋势；本机项目、缓存输入、非缓存输入、输出；当前周额度。
- 六种快捷日期和自定义范围，校验开始与结束日期。
- 项目悬停联动桑基，日期柱提示具体用量及类型构成。
- 项目行查看所选范围会话，日期柱查看单日会话。
- 会话搜索、用量/日期/输出排序、分页及各类 Tokens 明细。
- 键盘方向键移动日期柱，Enter查看会话，Escape关闭并恢复焦点。
- 读取失败、无记录、加载及搜索无结果状态；支持恢复操作。
- 1440×1000 与1280×800桌面窗口适配，尊重减少动态效果设置。

所有数据均为虚构，尚未连接MCP或真实账号。数据覆盖2026-01-01至2026-11-03。账号与本机明细各自统计，缓存已包含于输入，周额度独立于历史范围。

## 状态展示

本机预览可追加 `?state=empty`、`?state=error` 或 `?state=loading`。这些仅用于验收原型状态；加载状态约5秒后恢复，错误和空状态提供恢复入口。
