# Tokens 用量工作台

## 已确认的方向

用户选择第二轮 C「流量对照板」。保留石墨浅灰、暖白画板与低饱和赭灰；系统字体、细分隔线、紧凑控件、等宽数字；日柱、项目范围合计和桑基源节点逐行对齐。

主角是项目每日用量，主动作是选择项目或某日进入会话。固定项目→会话两层，不再引入仓库导航。所有统计使用全局日期范围，周额度独立展示当前窗口。

## 本轮范围

将已选方向整理为独立可交互原型；只处理页面、图表、弹窗和状态。数据均为虚构，不读取真实账号、会话日志或凭据，不接入MCP、不修改插件版本或安装状态。

保留两轮候选。正式原型不得引用`.oil-ui`过程目录；HTML、样式、数据和交互脚本均放在本目录，可直接离线打开。

## 内容与口径

- 官方账号：所选日期内总量与极简每日趋势。
- 本机项目：逐日用量、所选范围合计、会话数。
- 桑基：本机项目流向缓存输入、非缓存输入、输出；宽度按实际计数计算。
- 构成：缓存16.84M、非缓存3.87M、输出1.47M；默认近7天本机合计22.18M，官方账号28.64M。
- 缓存占输入81.3%，与缓存占全部Tokens75.9%的分母不同，分别标明。
- 本周额度62%，11月6日重置，不受历史范围切换影响。

## 交互与状态

- 全局日期：本周、近7天、近30天、本月、本季度、本年、自定义；输入校验保留原值。
- 项目行查看所选范围；日柱查看该项目当日；关闭会话弹窗回到原触发对象。
- 项目悬停联动桑基，日柱提供具体日期与Tokens提示。
- 会话明细支持搜索、排序、分页，展示同口径的缓存、非缓存、输出和合计。
- 完善空数据、加载及读取失败状态；仅为原型状态展示，不能声称真实接口已验证。
- 动效采用短促按下反馈、弹窗进入和首次内容出场，尊重减少动态效果设置。

## 设备与验证

主视口1440×1000，补查1280×800；桌面优先。长区间仅日期列横向滚动，项目与合计固定，桑基节点与项目保持对齐。

交付前检查真实截图、日期切换、单日与范围弹窗、搜索排序、键盘关闭与状态恢复。独立评审记录保存于本轮过程目录，不将设计意图当作通过证据。
