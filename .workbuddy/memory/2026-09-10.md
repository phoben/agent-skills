- `dist/icon-512.jpg` / `.png` — 512×512 市场图标，源文件 `dist/icon.html`（SVG），用无头 Chrome `--screenshot` 渲染
- `dist/上架提交材料.md` — 表单逐字段填写参考、市场文案、推荐提示词、自查清单

### 关键结论（可复用）

平台技能包规范（https://open.workbuddy.cn/docs/skill）：

- 包结构必须带一层 `{skill-name}/` 前缀，最多两级目录
- frontmatter 必填：`description`、`description_zh`、`description_en`、`version`、`author`；建议补 `display_name`、`display_name_en`、`category`、`allowed-tools`
- 资源引用用 `@references/xxx.md`，不是 markdown 链接
- zip ≤ 3 MB；图标 512×512、JPG/PNG、≤ 500 KB
- 表单里名称/版本/介绍由包解析、页面不可改，写错只能改包重传
- 平台审核：官方口径 7 个工作日内，实际常见 1–2 天
- 发布方式选「公开发布」才能进 WorkBuddy 市场

### 环境备忘

- Pillow 装不上（pip 无匹配分发），图标改用无头 Chrome 渲染 SVG → 可行
- Chrome 路径：`C:\Program Files\Google\Chrome\Application\chrome.exe`
- 渲染命令：`chrome.exe --headless=new --disable-gpu --window-size=512,512 --default-background-color=00000000 --screenshot=out.png file:///.../icon.html`
- 打包时注意把 CRLF 归一化为 LF，避免平台解析 edge case
