# 将 Issue Hub 纳入 YG Toolkit

日期：2026-11-04。状态：已采用；本机整合安装与旧数据恢复通过。

Issue Hub最初按同一yg插件源中的独立条目交付。用户希望统一工具箱的安装和升级，因此改为YG Toolkit内的模块，退休独立插件条目及其源码分发目录。

整合只改变安装与分发边界。Tokens和Issue Hub仍分别运行MCP与页面，各有一个global入口；缺gh不会阻断Tokens。YG双清单提供统一安装版本，旧独立插件版本不用于判断整合后的数据是否降级。

IssueHub业务目录、schema、稳定身份、工具名和UI URI保持不变。既有草稿、偏好、回执和聊天关联原地保留。新YG确认后旧独立插件保持停用或通过官方入口卸载插件缓存，不删除业务数据。

构建沿用Tokens入口串行生成两服务六产物，各保留独立许可；升版按同一YG归属检查两个源码模块，禁止将其他未提交工作打入包。Windows交接包含完整YG技能和双服务，不能只将原IssueHub八文件换目录。

从干净marketplace文件安装可避免复制用户工作区的其他技能脏改；已有源指针保留。既有本地源必须同步到整合代码，否则日后手动安装可回退旧包。实际协议、隔离安装与本机迁移分别验证，不能替代第二台Windows验收。
