# 以单插件入口和页面内仓库导航交付首版

日期：2026-11-03。状态：用户已确认。

用户原本希望像首页、资料空间、定时任务和代码审查那样，悬停插件图标即可使用原生浮层切仓库。官方 SDK 与当前宿主没有已证实的第三方通用接入契约；多个 global 工具只会增加主图标，不能满足该目标。

用户据此明确选择先在 Issue Hub 页面内导航仓库，继续完整 Issue 管理。首版只有一个 Codex 插件主图标，仓库选择与筛选状态由页面和本机偏好维护。代价是必须先打开插件页面才能切仓库；换取的是不依赖私有宿主桥接即可交付核心功能。

原生浮层不标记为已实现，也不通过注入或冒用内置插件来模拟。今后若公开契约可用，可在宿主适配层评估接入；仓库身份和业务数据继续由统一服务维护，避免将导航组件变成第二套业务来源。
