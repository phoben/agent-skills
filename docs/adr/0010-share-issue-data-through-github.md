# 通过 GitHub 共享 Issue 数据，插件状态保存在成员本机

日期：2026-11-03。状态：已采用；0.3.4完成本机验收，第二台Windows暂缓。

首版面向 Windows 团队分发，但不建设团队后台。GitHub 承担 Issue、标签和评论的协作数据来源；每位成员复用自己的 gh 身份，浏览偏好及聊天关联仅保存在各自电脑。这样可沿用已有权限与协作方式，减少服务部署和第二套团队状态的一致性成本。

曾考虑新增共享服务，让成员互相看到插件中的任务处理状态及聊天关联。用户明确选择只通过 GitHub 协作，因此这些本地信息不跨成员共享；若后续需要共享，必须重新设计身份、数据授权和同步边界，不能自动上传现有本地状态。
