# 在 Codex 查看 Tokens 用量

YG Toolkit 0.2.3新增用量页面。左侧插件入口打开后，可查看当前账号官方用量与本机项目统计，并沿项目或日期追溯会话。

## 安装与打开

安装前确保已登录Codex，并安装可用的Node运行时，建议Node24或更新版本。

```powershell
codex plugin marketplace add <本仓库目录>
codex plugin add yg-toolkit@yg
```

更新后新建聊天或刷新插件列表，使Codex重新发现MCP服务。在侧栏选择YG Toolkit的Tokens用量入口。首次索引历史记录可能需要等待，后续读取会复用本机缓存。

## 查看统计

页面默认近7天，可切换本周、近30天、本月、本季度、本年，或填写自定义开始与结束日期。单次范围最多366天，页面显示统计时区。

- 官方账号区域展示所选日期内已提供的消耗、每日趋势，以及可用时的累计用量。
- 项目矩阵逐日显示本机可确认归属的消耗。项目合计与桑基源节点逐行对应，所有日柱采用统一刻度。
- 点击项目行查看所选范围的会话；点击日柱查看该项目当天的会话。
- 会话明细支持搜索、按用量/最近活动/输出排序及分页，并列出缓存、非缓存、输出和合计。
- 顶部四张卡片分别展示账号总量、趋势折线、Tokens构成环图及当前额度；重置时间来自实际接口，不随历史筛选变化。
- 默认仅独立显示占本机用量超过1%的项目，其余合并为“其他项目”。点击“显示全部”展开；合并行和日柱仍可查看对应会话。
- 页面自动跟随Codex的浅色或暗色主题，独立浏览器预览跟随系统。

## 如何理解差异

账号官方数据可能覆盖其他设备和云端活动；项目明细来自这台设备已保存的会话记录，两者应分别阅读。

旧会话缺少账号标识时不会自动归入当前账号；其他账号也会排除。页面会说明归属、读取失败及部分覆盖的记录数量。官方接口未返回的日期显示覆盖不足，不能将缺口理解为0消耗。

缓存输入已包含在输入内，推理已包含在输出内。这里展示Tokens活动，不推算套餐金额、剩余Tokens或真实账单。

## 本机数据与故障恢复

源数据库和会话文件只读，独立统计缓存位于`CODEX_HOME/yg-toolkit/token-usage.sqlite`。服务不保存提示词、对话正文或认证令牌。

无法确认当前账号时，项目统计不会继续返回旧账号数据。可检查Codex登录状态后点击刷新。若页面暂时无法连接服务，检查Node、Codex命令及插件安装版本，再新建聊天或刷新插件列表。
