# Tokens 用量页设计决定

用户已确认 C「流量对照板」。项目逐日柱、所选范围合计与桑基源节点逐行对应，固定项目→会话两层。页面作为Codex内嵌MCP App使用，不另画宿主侧栏。

采用系统字体、等宽数字与低饱和图表色，自动跟随Codex浅色/暗色及宿主样式变量；独立预览跟随系统主题。日柱统一刻度且底部同线，流带宽度按真实计数，极小用量不人为放大。长日期区间只有日列横向滚动，项目和合计固定。

暗色参考Codex官方插件页的中性近黑画布与克制层次（用户确认）。页面使用宿主主背景，卡片在该背景上微微提亮，交互悬停再提高一层；不能直接把宿主次背景当页面、主背景当卡片而产生反向明暗。边框和轨道随文字与背景混合派生，减少大面积灰底、蓝灰底和强分隔线（具体混合比例为Agent推断）。浅色沿用原有设计。

顶部为四张独立圆角卡片：官方账号总量、趋势折线、本机Tokens构成环图、当前额度圆形进度。缓存/非缓存/输出全部移入顶部构成卡，不保留底部重复统计。删除原右上提示段，覆盖信息保留在页面下方；额度不跟随历史日期变化。

默认仅独立显示所选区间本机总用量占比严格超过1%的项目，其他项目合并为一行；显示全部/收起切换不改变计数与日期。合并项目的范围与单日会话仍可查看。侧栏使用统计柱形含义图标，并提供浅/暗资产。

交互包括全局快捷/自定义日期、项目范围/单日会话、搜索排序分页、分项计数、图表提示与联动、方向键导航、Escape返回和焦点恢复。缺失值保留未知，空集合和失败提供不同提示，异步只接受最后一次请求。

主验收视口1440×1000和1280×800。尊重减少动态效果。真实数据截图和操作记录属于本地验收过程，不随插件分发，也不作为公开产品示例。
