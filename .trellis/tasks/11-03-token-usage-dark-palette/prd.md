# 用量页暗色配色优化

用户已要求在合并后的main分支继续优化，参考其提供的Codex官方插件页截图。沿用已确认的C版结构与全部统计交互，直接调整配色，不重新探索布局。

## 目标

- 修正宿主变量导致的亮灰页面、近黑卡片反差，采用近黑画布、微亮卡片及中性悬停层次。
- 文字、分隔线、图表与弹窗保持可读；图表维持缓存、非缓存、输出的语义色。
- 宿主主题优先，独立预览跟随系统；浅色主题继续使用原有设计。
- 在1440×1000和1280×800检查真实页面，并验证带宿主变量的暗色场景与会话弹窗。
- 构建并安装本地补丁版本；用户随后明确授权更新版本并提交、推送main，最终版本为0.2.5。

## 修改边界

配色定义位于packages/token-usage/ui/styles.css。现有暗色将color-background-secondary映射给页面、primary映射给卡片；用户截图显示由此产生反向明暗关系。优先从共享变量修复，必要时微调交互表面的中性色，不修改数据、接口、布局或主题控制器。主代理负责版本、本地构建、验收与设计文档，实施代理只负责样式。
