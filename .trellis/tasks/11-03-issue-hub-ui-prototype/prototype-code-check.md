## 已修复

### 保存后评论按钮可能保持禁用

`app.mjs` 的 Issue 保存和关闭/重开成功分支原先在 `saving=true` 时重绘详情，导致新评论按钮带 disabled，finally 又未解除该按钮。现在在成功重绘前解除保存状态，失败恢复也在正确状态下渲染。

### 状态操作的迟到结果可能碰到新账号视图

关闭/重开原先没有固定身份、仓库和 Issue 的响应保护，账号变化后异常处理还会访问已清空的详情节点。现以发起时作用域核验结果，过期结果直接丢弃；异步动作由原事件链等待，错误节点使用存在性检查。

### 旧页面或草稿写入可能覆盖另一页面已保存的数据

`store.mjs` 原先按各实例旧内存比较 revision，另一个实例已保存后仍可能覆盖。远端演示写入现在先重读本机存储，再按编辑基线判断冲突；草稿、偏好、工作区绑定和任务记录的同步本地写入也先读回，避免把旧整份快照写回。

Issue 保存仅更新可编辑字段，不再把编辑时携带的旧 commentItems、作者和活动数组覆盖到最新对象，保留编辑期间新增的评论。

### 评论冲突与空草稿恢复

编辑评论保存固定 baseText；另一页面已更新时拒绝覆盖并保留当前输入。评论草稿带基线，编辑到空串不再因真假值回退到原文；清空新增评论后会删除原有草稿，立即刷新前也会尝试保存该删除意图。
