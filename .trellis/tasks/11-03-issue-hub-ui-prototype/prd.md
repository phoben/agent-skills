# 设计 Issue Hub 页面导航与交互原型

## 目标

使用 oil-ui-pro 探索三个页面内仓库导航方向，选定后制作可交互原型并取得用户确认

## 已确认范围

- 用户已明确选择：一个 Codex 插件主入口，进入 Issue Hub 页面后切换仓库；本阶段不接原生悬浮侧栏，不增加主导航图标。
- Windows 团队使用，每人 gh 身份；列表浏览、完整详情/评论、日常编辑、前台 60 秒同步、离线草稿及会话行为沿用父任务。
- 用户已根据三首屏明确选择 A 连读队列：仓库与队列保持可见，详情相邻。只深化 A，不再改 B/C 或重新探索风格。
- 当前轮制作完整交互原型及主要/异常状态、浅深主题和两档可用画布，不改安装中的 P0 或正式产品代码。
- 原型不写 GitHub、不创建真实聊天；正式界面开发须等待原型确认。总体开工授权已具备，不再次询问是否创建或开始任务。
- P0 单入口及 MCP 基础已有验证；真实项目覆盖和会话验收继续保留到相应集成阶段，不以模拟原型标记它们通过，也不因此阻塞独立 UI 探索。
