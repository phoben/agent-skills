# 列宽、单击与加载速度验收

2026-11-04。已按用户截图实施三项改进，最终交付并安装 **Issue Hub 0.2.2**。原计划为0.2.1；安装时该版本缓存已存在且被占用，CLI返回“failed to back up plugin cache entry / 拒绝访问”。没有覆盖或删除被占用缓存，使用新的0.2.2目录安装。0.2.2只更新版本元数据，业务逻辑与最终验证的0.2.1候选相同。

## 用户可见变化

- 项目栏与Issue队列的右边界可拖动，范围164–420px和280–640px，并给详情保留至少360px。宽度与上次仓库保存在当前账号的本机SQLite，窄窗仍用项目抽屉。分割线支持键盘调节、Enter/双击恢复单栏默认和按钮恢复两栏默认。
- 单击切换项目和Issue。选择与加载反馈先显示，浏览偏好、评论/活动、候选和会话不再串行挡住正文；草稿保存失败仍保护输入，快速选择以最后一次为准。
- 再次进入优先显示当前已验证凭据对应的缓存目录、列表和正文，后台继续严格核对更新。无缓存首次仍读取真实账号与项目。缓存不冒充新鲜数据，未加载讨论不显示为无评论。
- 后台仓库归一、配置更新或临时目录读取失败不会把用户刚选中的项目跳回首项或清空详情。Codex只读连接可自行重连；真实GH身份变化/401/403仍清旧投影。未经重新核对的工作区仍不允许打开任务。
