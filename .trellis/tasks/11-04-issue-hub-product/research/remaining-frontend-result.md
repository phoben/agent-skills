# 剩余会话与连接检查前端结果

2026-11-04，按 remaining-030 的已授权范围实施，保留 A 布局、中性主题、列宽、单击和分阶段读取。源码已初步冻结，供 root 统一集成与实际验收。

## 会话操作

- 会话菜单和当前任务弹层均有“修改工作区”。即使现有绑定有效，也能打开选择器。保存只调用 bind，既有当前/历史会话仍显示原工作区；新绑定明确用于后续另建。取消不调用 bind 或 open。
- “历史任务与会话”展示服务返回的自有记录，仅已确认记录提供返回按钮。页面只传 Issue 归属的 requestId 调用 open-history，不接收任意 threadId；返回后不将历史设为当前优先任务。
- 歧义或部分覆盖中的已核验候选由服务返回，前端不按标题、时间猜测，也不默认代选。明确选择后调用 resolve，携带当前 requestId、服务候选 threadId 和 confirmed:true，交服务再次核验。候选或当前请求改变时拒绝旧选择。
- 任务引用只展示服务的 reference 完整首行；请求 ID 不再标作任务引用。预填说明提醒保留首行，仍由成员在 Codex 手动发送。
- 新增任务操作代次和弹层代次保护：迟到的 latest/resolve/历史响应不能覆盖较新请求或较新弹层。后台更新只改会话关系区，避免重绘当前输入。

最终 MCP task 动作字段已与任务代理对齐并交 root：`open-history {repositoryKey,number,requestId,expectedIdentity}`；`resolve {requestId,threadId,confirmed:true,expectedIdentity}`。返回仍是 current/history/binding/workspaces 投影。

## 连接检查

导航底部、窄窗仓库抽屉和加载失败状态均可进入“连接检查”。该入口直接调用空参数 `issue-hub-diagnostics`，不依赖已成功 bootstrap、已选仓库或 GitHub 身份。

沿用现有弹层展示检查状态、版本、登录说明、修复建议和项目发现限制。只读取诊断契约字段，转义显示文字；不显示额外 token/stderr/raw/error 对象，也不执行修复建议。请求本身失败时使用固定安全说明，不透传原始异常消息。关闭或重新检查后，旧响应不再覆盖新弹层。宿主已断开时仍允许打开说明入口，实际检查失败会明确提示重新打开插件。

新增模块为 `ui/task-views.mjs`、`ui/diagnostics.mjs`，并修改 app/store/ui 与小范围弹层样式。未修改服务端、版本、构建或安装产物。

## 已确认提交尚无新投影时的读取恢复

真实闭环后，后端新增 confirmed 重放的最新投影读取；读取失败保留成功回执并返回 issue:null。本轮只对齐相关前端路径：Issue、评论和状态的空投影异常均携带 operation；confirmed 与 readback-failed 都属于已接受提交，只提供重新读取，不显示未知创建或解除重投入口。

实际控制器在连续读取仍返回 issue:null 时，保留成功回执、当前标题/正文/评论和读取入口，不清理成可重新发布状态。仅取得有效 Issue 投影后才结束恢复并更新页面。状态变更的错误路径也保留该恢复入口。

新增 `product-ui-readback.test.mjs` 三项回归通过，包含三种保存类型的回执/草稿保留、confirmed 只读入口、实际控制器连续两次空读回后仍保留输入，第三次取得投影才清理。既有未知创建、人工解除和已接受写入重读三项定向回归通过；47 模块语法和受影响文件空白检查通过。源码已再次冻结并交独立检查，不触碰诊断或会话服务，也未自行执行真实写入。

## 真实 60 秒轮询的详情绘制修复

root 对验收 Issue #5 的真实远端临时标题修改发现：页面前台且未手动刷新，列表行已经出现远端新标题，详情标题仍旧；[原轮询记录](browser-poll-030.json)在 110 秒等待后超时。源码原因是 refresh 只允许手动分支整块重画详情，随后 hydrateIssue 在 strict 摘要已到、cached=false 时不再绘制摘要；详情标题的程序焦点又会被整体 contains(activeElement) 阻挡。

先增加准确红回归，直接执行改动前实际 refresh：manual=false、strict 数据已到、H1 仍聚焦，列表更新但详情标题断言失败。修复后该回归变绿。新增 `ui/summary.mjs` 只更新现有标题、作者、状态、属性和正文/来源链接子区；完整详情渲染记录原始正文，正文未变化时不替换节点。标题 H1、属性按钮、评论输入节点和焦点均保留，读取区滚动位置保留；只有正在使用的正文或链接控件使对应子区暂缓，离开控件后局部补画。

自动与手动刷新都使用局部摘要绘制。正在回复评论时继续读取最新摘要，但不重建评论编辑器、不改输入或选择范围。正在编辑 Issue 正文时不覆盖表单，远端版本变化给出明确旧投影提示。strict/cache-first 后台摘要完成也走同一绘制函数，避免同类漏画。

新增轮询回归 5 项，连同已有体验 11 项共 16 项通过；49 模块语法与受影响文件空白检查通过。改动仅 app、summary helper 和 UI 回归；服务与核心 Store 未改。真实 60 秒复测由 root 复用 Issue #5 完成，不以隔离红绿代替其结果。
