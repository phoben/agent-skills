# A 连读队列：当前原型基线

用户已从第 01 轮真实首屏中明确选择 A。此文件为短上下文，防止完整三方向卡被截断；不再把 B/C 作为当前实现候选。

## 画面与布局

- 以 [已选首屏](evidence/round-01/final-a/page.png) 为视觉基线。左侧仓库导航 164px、Issue 队列 316px，右侧详情占剩余宽度；整体可伸缩，不裁成固定尺寸。
- 首次进入列表，打开详情后队列收窄，标题/正文完整显示；关闭回同一 Issue 和滚动位置。
- 1120×880 为主画布预算，960×680 时仓库收为页面抽屉、队列 280px、详情余宽；更窄单详情并提供返回。
- 系统字体，正文 14px、标题约 18px、辅助文字至少 12px；墨绿选择状态与主操作，紧凑专业工具，不加欢迎区或指标卡。
- 浅色基础：导航 #eef2f0、主区白、正文 #1d2c25、辅助 #53665a/#5f7166、强调 #236248、选择底 #e5f0e9。深色从 A 色板映射，重要信息与操作至少保持可读对比。

## 当前制作范围

`prototype/a-v1/` 是独立、可运行的演示前端，原生 DOM/ESM、CSS 变量与少量模块。不改现有安装包，不引远程 CDN，不调用真实 GitHub 或 Codex。默认主题可按系统，QA 可通过 theme 参数查看浅深变体。

列表、仓库/筛选、详情、正文编辑、标签/负责人/里程碑、评论、关闭/重开、离线草稿与会话演示均可操作。保存应通过本机持久化，刷新可读回；错误和冲突必须从真实本地操作触发，不能仅摆终态。

共用交互与身份边界以 [interaction-contract.md](interaction-contract.md) 为准。按钮标签沿用“创建任务／返回会话／另建任务”，一个有效工作区单击，不自动发送。完整真实集成仍属于后续阶段。

## 验证顺序

先由主 Agent 操作保存、刷新、失败恢复及身份隔离，再取得代表状态和复杂状态的真实画面；独立视觉及开放式 UX 检查后交用户确认。选定 A 不是最终原型确认，也不代表真实后端通过。
