# 原型共用交互约束

本页是小体积任务上下文，完整布局见 direction-cards.md；用户选择方向后还需读取所选章节，不能把本页当作全部视觉设计。当前只是已复核的原型约束，尚未渲染或用户确认。

- 首版一个宿主主入口，进入页面后切仓库。模拟原型不写 GitHub、不真实打开或发送聊天。
- 无确认关联时主动作“创建任务”，一个有效工作区单击即准备并打开未发送草稿；有确认关联时为“返回会话”。会话操作菜单明确含“另建任务”，保留旧关联，生成新独立引用；首次多路径或路径失效才确认工作区，取消不产生请求。
- 新请求未确认、等待发送、多匹配与已关联分别展示，不用“请求已发出”冒充已建立会话；未知映射不写“未关联”。
- 账号变化清除旧私有视图与在途响应，缓存、草稿和关联按身份隔离，不能只停写仍展示旧内容。
- 切仓库、切 Issue、关闭详情前保留原作用域本机草稿；本地保存失败阻止离开，提供重试、放弃或继续编辑，不自动发布远端。回原对象恢复草稿与位置。
- 仓库列表、选择器或页签以方向键移动焦点，Enter/Space 明确选择。Issue 列表上下键移焦、Enter 打开；编辑器内方向键和 Enter 仍用于编辑，不设置全局回车发布。
- 打开详情聚焦标题，关闭/返回回原行与滚动；原行被筛选移除时回列表标题。弹层限制焦点，Esc 回触发器；编辑器内 Esc 不关闭整份详情，菜单/弹层优先处理。
- 保存错误贴编辑内容，冲突比较保留输入，评论失败不清空。后台刷新、断网与限流提示不夺焦点；用户主动提交错误才聚焦摘要或字段。
- A 小画布为 960×680、队列 280＋详情 680，仓库退到抽屉；B 由全宽表格进入单阅读页，属性轨收一行；C 保留完整关系文字、原行展开，溢出仓库可完整选择。数字为概念预算，实际宿主尺寸待测。
- 视觉方向选择与原型最终确认分别记录；文字/灰度通过不代表实际视觉、交互或集成验收通过。
