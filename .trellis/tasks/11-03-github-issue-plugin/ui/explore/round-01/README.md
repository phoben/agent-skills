# Issue Hub 首屏对比 · 第 01 轮

这是用户要求的三张静态首屏，不是完整交互原型或已接入的 Issue 管理页。内容只来自同目录 fixture.json，三张共用同一仓库、Issue #184、正文、评论和“返回会话”主动作。

比较场景为“已经选中同一条 Issue，准备继续处理”：A 保留旁侧队列，B 进入全宽阅读页，C 在原列表位置展开。因此 B 本轮不额外塞入列表缩略图，它的列表视图在选定方向后的交互原型中实现。

三张均采用 1120×880 插件画布和浅色主状态，结构与样式分别生成，不按明暗换皮。此轮没有候选交互、响应式或动效；按钮是静态呈现，不执行 GitHub 写入或真实聊天动作。深色与小窗口在选中后的完整原型验证。

每个 build-a/b/c.mjs 只从共享 fixture.json 读取内容并输出自己的 HTML，候选在禁用脚本时仍可显示。对比页由 oil-ui-pro 的 build_explorer.py 生成，不另写对比外壳。

用户可在对比页并排或单张查看、按 100% 看文字，选择后将生成的方向文字贴回本聊天。选择按钮只复制文字，不替用户批准或自动写回任务。

源文件与截图由任务记录维护；本目录不会改变安装中的 P0 验证插件，也不用于证明真实宿主会话或 GitHub 业务验收。
