# 第 01 轮首屏交付与检查

用户已要求先看三首屏，不代表已选 A/B/C。本轮仅静态主状态，未写候选交互、响应式、动效或完整流程；没有访问 GitHub、写远端或创建真实聊天。旧版 P0 验证页及插件安装未改。

## 入口与一致性

- 在线对比：`http://127.0.0.1:18284/style-explorer.html`，只监听本机，服务根限于本目录。
- 离线产物：[style-explorer.html](style-explorer.html)，由技能 build_explorer.py 生成，可离线查看，不另写对比外壳。
- 全部来自 fixture.json；固定 1120×880、浅色、team/issue-hub、Issue #184 和“返回会话”。可见评论条数随版式空间不同，数据仍来自同一份预览评论。
- 各方向独立骨架和 CSS。A 保留队列，B 展示独立阅读首屏，C 原位展开；不为 B 添加小型列表截图来凑成同构多栏。

## 实际执行

- 三个 Node 静态生成器执行成功，产物无运行脚本和外部资源，禁脚本仍显示完整内容。
- 技能 build_explorer.py 生成并在 A 修正后用 --force 重建；最终 fingerprint 为 `ae8c1a3f84daa9d17cc99899`。
- shoot.mjs 一次获取 A/B/C 与总览，1120×880、无状态或设备矩阵；主 Agent 实际看过三张原图和总览。
- 初次 A 有 10 处对比度提示。将辅助文字 #5c6d64 调为 #53665a，#748278 调为 #5f7166，只重生和重截 A；新报告没有对比度问题。
- B/C 未改，沿用首轮图，不重复取证。最终总览由修正后的 A 与原 B/C 拼合。
- 检查没有控制台错误、横向溢出或加载失败图片；未宣称完整可访问性、交互验收或独立视觉评分。
- 自动打开对比页时，先前参考研究的 ego-browser 任务空间 7 已不存在，未新建空间绕过。该失败不影响本机 HTTP 入口、离线文件与已看过的真实截图；不声称已经替用户在浏览器里打开。
- 首次拼图误用了 idle.png，工具实际输出 page.png；改为正确文件后拼图成功，没有因此重截未改的页面。

## 保留的默认做法提示

| 候选 | 保留项 | 理由 |
| --- | --- | --- |
| A | 选中队列行的墨绿单侧边条 | 表达当前阅读对象和稳定位置，是方向的业务识别，不是装饰边框。 |
| B | 正文锚点的细侧边线 | 表达当前阅读段，帮助长正文定位，不在内容外叠加卡片。 |
| C | 当前展开 Issue 的靛蓝边条 | 标记展开对象归属，并与有文字的关联状态对应，不表达虚构进度。 |

三张从一开始就未加入欢迎语、指标卡或营销说明，本轮无需为“删字”额外改动。原型模拟和未接入范围写在本交付说明，没有放进候选产品画面。
