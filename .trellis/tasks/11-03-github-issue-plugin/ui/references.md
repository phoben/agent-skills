## 产品参考一：GitHub Issues

来源：[microsoft/vscode Issue 列表](https://github.com/microsoft/vscode/issues)。实际打开并读取了页面 DOM。

可核查的结构信息与取舍：

1. 仓库上下文与 Issue 内容分开；Issue Hub 保留明确仓库上下文，但不复制 GitHub 的代码、PR、Actions 等整套全站导航。
2. 搜索表达式、状态页签、作者/标签/负责人/排序等控件贴近列表；保留就近筛选，避免独立设置页。
3. 状态、编号、标题和元信息在同一对象行中分层；保留可扫描的标识，不把每个 Issue 包成大卡片。
4. 列表提供两档显示密度；只作为密度依据，首版是否增加密度切换不因此扩范围。
5. 当前页面有明确筛选对象与状态控件；Issue Hub 按已确认需求区分空仓库与无匹配，不声称本轮观察到 GitHub 的全部空态。
6. 详情中的正文动作、属性和讨论有不同区域；完整正文及分页评论保留，不用摘要替代。
7. 置顶 Issue、贡献引导和全站导航不直接复制到插件；专业工作区应先显示当前待处理对象。

外观结论限制：未取得截图，不评价 GitHub 的具体色相、间距、图标细节或视觉完成度。
