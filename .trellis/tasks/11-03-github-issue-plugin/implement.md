- 新增独立产品包和插件目录，现有 Tokens 只作为参考，不因新功能修改其页面或统计行为。
- `.agents/plugins/marketplace.json` 追加独立条目。
- `.codex/hooks/bump_plugin_version_before_push.py` 和对应测试扩展插件注册表、差异归属及首次发布；只改 Issue Hub 时不能误升 YG。
- 新增受影响的开发规范与安装文档；本轮规划文档不替代实现后验证的规范。
- UI 设计说明、候选、原型、截图与评审记录放在本任务 `ui/` 下，按需创建；正式产品只实现用户确认的方向，不覆盖现有 Tokens 页面。

## 验证层次

- 协议与业务边界：分页、PR 排除、remote、身份隔离、并发、结果未知和限流。
- 包外 MCP：安装产物启动、工具与 UI 发现、参数和失败路径。
- 浏览器模拟宿主：交互、主题、分页和错误状态。
- UI 原型：选定方向、1440×1000 与 1280×800、浅深主题、键盘与焦点、长标题和长评论、关键状态与开放式 UX 走查；用户确认记录单独保存。
- 真实 Codex 与 GitHub：原生仓库侧栏、完整项目发现、非空 Issue 与评论、写后读回、工作区新聊天草稿。
- 团队环境：第二台机器独立安装授权，以及已确认支持的系统和版本。

## 回滚点

- P0 仅最小验证插件，不覆盖现有插件安装；失败可移除该独立验证产物。
- 插件和缓存独立升级，schema 迁移前备份；回滚时避免旧代码打开新 schema，不能丢失未发布草稿。
- 升版钩子保留现有 YG 的行为测试及受影响插件隔离；新注册规则失败时不继续推送。
- GitHub 已成功写入的业务内容不会因回滚插件自动撤销；回执保留以便后续核对。
