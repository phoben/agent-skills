# P0 实现与验证记录

日期：2026-11-03。实现代理负责 `packages/issue-hub/`、`plugins/issue-hub/` 及本记录；根 marketplace、安装和独立宿主发现由主 Agent 协调。没有提交、推送、GitHub 写入或自动发送聊天。

## 已交付

- 独立 Node 24 ESM 包与锁文件，当前修订版本为 0.1.1，双插件清单与服务/UI 版本一致。
- 受限 App Server RPC：项目、身份和明确待关联范围的聊天只读方法；进程关闭、协议帧大小、超时与配置/身份变化检查。
- 已注册项目 roots 的直接 Git 仓库发现、全部命名 remote 读取、github.com 地址归一化和工作区绑定；失败分类不回显目录或原始错误载荷。
- 默认两个仓库 global 入口，共用内联 UI，入口携带仓库上下文，目录刷新产生 MCP 工具清单变更。
- 最小技术验证页面；工作区绑定、无项目操作的中文验证草稿、唯一任务引用、仅已确认 thread 的返回链接。该页面不是 U1 风格或原型验收产物。
- 本机独立请求状态与重复请求去重；未确认、覆盖不全及多匹配不会被冒充已关联。不保存聊天正文或凭据。
- 自包含 CJS、内联 HTML、第三方许可、自有图标和仓库 MIT 许可；开发依赖不要求存在于安装包外。

## 实际运行

以下为实现代理在 0.1.1 修订冻结时执行的结果。独立评审如继续修改代码，应重新构建并复核，不把本记录当作后续修改的自动通过证明。

| `npm install --prefer-offline --ignore-scripts` | 独立目录安装完成，未修改旧包；随后离线更新本包锁文件版本。 |
| `npm test` | 17 项通过：RPC 允许列表/启动关闭/超大帧；真实隔离 Git 仓库；分页/失败分类/目录变更；MCP 双入口、上下文与工具变更；nonce 单一/歧义/部分覆盖、身份切换、损坏状态；UI 初始结果竞争与切换仓库后丢弃旧响应。 |
| `npm run check` | 18 个 JavaScript 模块语法检查通过；本包为 JavaScript，不将其称为 TypeScript 类型检查或独立 lint。 |

| `npm run verify:stdio` | 从系统临时目录启动独立产物；恰好 2 个仓库入口、global/app-only 元数据、独立入口上下文、UI 资源及非法参数拒绝通过。少于 2 项会明确失败。`desktopVerified=false`。 |

## 已移交独立评审的恢复问题

实现后自查发现：OS 深链打开草稿可能导致 MCP 页面销毁，页面内存中的请求标识会丢失；虽已持久化 pending，本版界面尚缺少按当前工作区恢复该请求的入口。已通知主 Agent，由独立检查代理统一补充读取自有最新请求及页面恢复的回归测试。此处只记录发现，不提前宣称修复通过；其最终结果由检查代理补充后再冻结产物。
